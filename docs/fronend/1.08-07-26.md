## 1) คลังหลักฐาน (Evidence Vault) — เห็นเฉพาะผู้รับผิดชอบ + เอา Upload ออก

**ทำอะไร**
- `/evidence` เขียนใหม่เป็น client — กรองหลักฐานผ่าน `evidence.case_id` → คดี → `visibleCases(user)` (admin เห็นทั้งหมด, หัวหน้าเห็นของตัวเอง+ลูกน้อง, ลูกน้องเห็นเฉพาะคดีที่ถูก assign), wire ค้นหา/category/status ให้กรองจริง
- `/evidence/[id]` แปลงเป็น client + **guard `canSeeCase`** (กันเปิดผ่าน URL ตรงของคดีที่ไม่มีสิทธิ์)
- **ลบปุ่ม Upload ทุกที่**: เมนู "Upload Evidence" ใน Sidebar + ปุ่ม Upload ในหน้ารายละเอียดคดี

**ทำไม**
- หลักฐานเป็นข้อมูลอ่อนไหว ต้องเห็นเฉพาะผู้รับผิดชอบคดี (need-to-know) · admin เห็นภาพรวมเพื่อกำกับดูแล

**ไฟล์:** `app/(dashboard)/evidence/page.tsx`, `evidence/[id]/page.tsx`, `components/layout/Sidebar.tsx`, `cases/[id]/page.tsx`

## 2) หน้าอัพโหลดหลักฐาน — เฉพาะผู้รับผิดชอบคดี, admin ไม่มีหน้านี้

**ทำอะไร (2 รอบ)**
- รอบแรก: guard หน้า `/evidence/upload` — admin โดนปฏิเสธ, dropdown เลือกคดีเหลือแค่ `visibleCases` ของตน, ใช้ผู้ล็อกอินจริงแทน `currentUser` mock; เพิ่มปุ่ม "อัพโหลดหลักฐาน" ในหน้าคดี (เฉพาะผู้รับผิดชอบ) ส่ง `?case=<id>` มา
- รอบสอง (ปรับตามข้อเสนอ):
  - **ตัด step เลือกคดีทิ้ง** (คดีมาจาก `?case=` + แบนเนอร์บอกคดี; เปิดตรงไม่มี case → พาไป `/cases`) → wizard เหลือ 3 ขั้น
  - **เปลี่ยน Location = "สถานที่เกิดเหตุ"** เป็นชื่อสถานที่ (prefill จากคดี) + **พิกัด lat/long**
  - **เอา 2 การ์ด settings (Watermark/Blockchain) ออก** → ทำเป็นอัตโนมัติ (integrity บังคับเสมอ ไม่ให้ปิด)

**ทำไม**
- สร้าง/อัพหลักฐานต้องเป็นผู้รับผิดชอบเท่านั้น (chain of custody) · admin เป็นผู้กำกับ ไม่ใช่ผู้ปฏิบัติ
- watermark/blockchain คือความถูกต้องของหลักฐาน จึงไม่ควรเป็น option

**ไฟล์:** `app/(dashboard)/evidence/upload/page.tsx`, `cases/[id]/page.tsx`

## 3) พิกัดสถานที่เกิดเหตุจาก EXIF ของรูป (แก้ปัญหาอัพย้อนหลัง)

**ทำอะไร**
- เขียน **EXIF GPS parser เอง** (ไม่เพิ่มไลบรารี) `utils/exifGps.ts` — อ่าน APP1/TIFF/GPS IFD ของ JPEG → คืน `latitude/longitude` (+`takenAt` จาก DateTimeOriginal)
- ตอนเลือกรูป: ถ้ามี GPS ฝัง → เติมพิกัดอัตโนมัติ + badge "พิกัดจากรูป (EXIF)" และ prefill วันเวลาถ่าย; ถ้าไม่มี → ให้กรอกเอง
- ช่อง lat/long **กรอก/แก้เองได้เสมอ** (เผื่อภาพจากบุคคลที่สาม เช่นนักข่าว) + แสดงแหล่งที่มาพิกัด + ลิงก์ "ดูบนแผนที่"

**ทำไม**
- ถ้าใช้ "ตำแหน่งปัจจุบัน" ตอนอัพ จะได้พิกัดที่อัพ (เช่นออฟฟิศ) ไม่ใช่ที่เกิดเหตุ — พิกัดจริงต้องมาจาก metadata ในรูปที่กล้องฝังตอนถ่าย จึงถูกต้องแม้อัพทีหลัง

**ไฟล์:** `utils/exifGps.ts` (ใหม่), `evidence/upload/page.tsx`

## สรุปสิ่งที่ backend ต้องทำต่อ (เฉพาะรอบนี้)
1. **Evidence API**
   - `GET /api/evidence` — คืนหลักฐาน**ตาม scope ของคดี**: admin=ทั้งหมด, ผู้รับผิดชอบ=เฉพาะคดีของตน (creator/assignee/สายบังคับบัญชา); `GET /api/evidence/{id}` เช็กสิทธิ์รายชิ้นด้วย
   - `POST /api/evidence` — **เฉพาะผู้รับผิดชอบคดี (non-admin)**; รับ `case_id` + สถานที่เกิดเหตุ (**ชื่อ + latitude/longitude**) + category/description/captured_at; **ฝัง watermark + บันทึก blockchain ฝั่ง server เสมอ** (ไม่เป็น option)
2. **Watermark extraction API** (ทีมเพื่อนทำ logic) — endpoint แกะลายน้ำต้อง **admin only**; คืน officer/timestamp/GPS/tamper ที่ดึงได้จริง
3. **Location/พิกัด** — เก็บ lat/long ของจุดเกิดเหตุในตาราง evidence (พิกัดถูกดึงจาก EXIF ฝั่ง client แล้ว แต่ server ควร validate/normalize)
4. **Authorization ต้องบังคับซ้ำที่ backend** — ทุกอย่างข้างบนตอนนี้เป็น **client-side guard สำหรับ demo** เท่านั้น; ตรรกะสิทธิ์ต้องตรงกับ `caseAccess.ts` (ยศชั้นสัญญาบัตร=สร้างได้, admin=ดูอย่างเดียว, สายบังคับบัญชา=ขอบเขตการเห็น)
